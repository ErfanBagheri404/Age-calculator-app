# Age calculator app

![Design preview for the Age calculator app challenge](./design/desktop-preview.jpg)

Solution to the Frontend Mentor **Age calculator app** challenge - a responsive calculator built from the provided design.

**Live demo:** https://erfanbagheri404.github.io/Age-calculator-app/

## Built with

- Semantic HTML5
- CSS custom properties, Flexbox and media queries
- Vanilla JavaScript for the interactive behaviour (no framework, no build step)
- Bundled webfonts and SVG assets from the challenge starter files

## Run locally

```bash
git clone https://github.com/ErfanBagheri404/Age-calculator-app.git
cd Age-calculator-app
```

Open `index.html` in a browser. Nothing to install or compile.
